# 远程任务工作台

这一入口用于照看已有训练、网站和定时任务。任务保存服务器、目录、日志和进程关联；登记或移除任务不会启动/停止远程进程，也不会删除远程文件。实现与验收状态见 [本轮记录](../project/remote-workspace-20261103.md)。

## 第一次连接

1. 打开「任务工作台」，添加服务器名称、地址、SSH端口和用户名。普通SSH填写密码。
2. 探测主机指纹，核对地址和指纹。指纹应通过你信任的服务器控制台或已有可信记录确认；软件探测到的指纹本身不能证明服务器身份。
3. 确认信任后检查连接。目标或主机密钥变化时需要重新核实。

Tailscale 可选：已经使用 tailnet 时，可以填它的设备地址并继续使用普通SSH。若目标已启用 Tailscale SSH，可以显式选对应认证模式；软件不会为你开启服务器SSH、登录tailnet或修改访问策略。本机设备发现依赖运行后端的机器已安装和连接Tailscale；服务器列表与已授权访问不是一回事。Tailscale SSH需要额外交互认证的情形尚未实网验收。

## 固定一个任务现场

选择服务器、新建任务，填写自己的名称和类型。通过目录选择器选工作目录，通过进程列表选择正在运行的任务；暂时不绑定进程也可以登记。日志从文件列表点选，必须位于工作目录内。

- 训练：关联实验目录、训练进程和日志，之后直接查看现场和下载结果。
- 网站：登记工作目录、日志和可打开的URL；URL入口不代表已进行HTTP健康检查。
- 定时任务：登记脚本/输出目录与时间说明；这是已有任务的工作现场，不会自动安装cron或创建新的调度。

进程关联保存启动身份。PID被复用不会把新进程当成原任务；原进程消失只能说明当前无法找到它，不能据此判定训练成功。日志更新也不自动代表模型有进展。

## 查看与取回结果

详情中查看采集时间和模块可用性。日志以文本显示，最多读取尾部64KiB；文件树支持进入目录、预览文本和下载文件。缺少GPU工具时显示不可用，不能将它解读为GPU利用率为零。

文件操作限制在任务根目录，符号链接和特殊文件不跟随。下载上限16MiB；超过时使用专用传输工具或终端。当前不是完整的大模型权重传输工具。终端可以在选定目录打开，连接使用短期单次票据；会确认交互shell实际进入该目录后才显示已连接。此功能要求POSIX兼容shell，特殊shell可能返回明确失败或超时。

执行记录是人或Agent明确上报的记录，显示“上报记录”。它与现场采集分开，不是软件独立确认的成功证明。

## Agent 共用同一个任务

CLI通过同一API访问同一账号下的数据，不直接另走SSH。先按CLI帮助配置面板URL和登录Bearer凭证；凭证通过 `PANEL_TOKEN` 环境变量或 `--token-file` 传入，不放命令参数和示例文件。凭证可从标准 `/api/auth/login` 获得；本轮未实现独立Agent委派权限。

```bash
python scripts/panellab.py --help
python scripts/panellab.py tasks list
python scripts/panellab.py observe 1
python scripts/panellab.py logs 1
python scripts/panellab.py files 1
```

示例中的1替换成UI显示的任务ID。创建、更新和上报支持JSON文件或标准输入。CLI输出结构化JSON；失败返回非零退出码。下载默认不覆盖本地文件；移除登记需要明确确认，远程任务不会因此停止。

本轮未内置聊天模型、MCP服务器或自动运行任意命令的Agent。可通过现有API/CLI让你选择的Agent操作任务对象。
