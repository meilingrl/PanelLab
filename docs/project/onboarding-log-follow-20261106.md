# 本地首次启动、Agent 接入与日志跟随

基线为 `0d2bdef`，开发分支为 `feat/onboarding-log-follow`。本轮围绕一个使用场景：先启动自己的面板，把训练登记一次，以后由人或外部 Agent 直接查看它的日志。

## 如何试用

1. 按[本地启动说明](../deploy/deploy.md)运行 `python3 scripts/local_panel.py`，待服务就绪后打开打印出的地址。初始密码通过同一脚本的 `password` 命令查看。
2. 在[任务工作区](../user/remote-workspace.md)添加自己的 Linux 服务器，核对 SSH 主机指纹，选择训练目录和日志。打开「日志」并勾选「自动跟随日志」，向上翻可以留住报错所在的位置。
3. 若要让外部 Agent 查看同一个任务，按[MCP 接入指南](../user/mcp-access.md)运行 `--setup`，将生成的配置加入所用客户端。凭据继承当前面板账号权限。

## 验证记录

- 本地启动器在 macOS/Colima 上实际构建打包前后端并启动 MySQL 8.4.9，验证了登录、修改密码、保存 SSH 凭据，以及停止并重新创建容器后的数据与凭据解密。Web 只发布到回环地址，MySQL 只在实例网络内监听。此机 Docker 数据分区在首次建库时返回 ENOSPC。成功的完整运行使用同一 Compose 配置，另为该测试实例的命名卷绑定一块有空间的目录。该次验收不能证明默认数据盘已有足够空间。
- 独立的一次性 Linux OpenSSH 与 MySQL 夹具验证了任务根目录、文件类型限制、主机指纹变化拒绝、终端连接，以及 CLI 和 MCP 读取。通过真实伪终端输入测试账号，`--setup` 创建权限为 0600 的新凭据文件；以生成的 JSON 启动 SDK 客户端，发现 8 项工具，读到了该训练任务的 ID 和对应日志。
- 在浏览器中对同一个训练任务开启两秒跟随，观察输出从第 46 步增至第 49 步。向上翻页后阅读的末行保持第 51 步，点击「回到最新日志」后显示第 58 步。轮换、超长日志、慢请求、退避和同 ID 改绑另由自动化用例覆盖。[浏览器截图](assets/task-log-follow.jpg)
- 日志来自模拟训练程序，真实走 SSH/SFTP。此次验证使用临时账号和数据。个人服务器、实际训练任务、真实弱网、私钥接入和特定 Agent 客户端的配置界面仍待试用。

## 独立审查与收尾

日志读取与接入流程由实现者以外的审查者分别检查。按复现修复了首次读取中途离开导致空白、绑定文件与响应路径不符时显示错误日志、工作区书签带尾斜杠时返回 404，以及接入说明指向旧端口。启动器现在在构建前确认并固定本机 Docker 套接字，拒绝可被其他用户替换的凭据目录和文件。独立复审核至 `06a8a71`，反馈均已关闭。

本地运行通过后端 193 项、前端 150 项、MCP 137 项和启动器 18 项，前端生产构建通过。修订后的启动器再次在隔离卷上完成实际构建、登录、停止与重建，已有登录和 SSH 凭据仍可使用。测试实例已回收。收尾时 `colima ssh -- df -h /var/lib/docker` 显示可用 295 MiB；此机使用默认卷首次启动仍需先解决 Docker 数据盘容量。该分支的直接推送不触发仓库现有 CI。

## 下一步

用真实训练或早报任务走一遍「第一次接入、第二天回来查看」的流程，先核对 SSH 认证方式和真实连接下的等待时间，再决定任务操作与传输的优先级。
