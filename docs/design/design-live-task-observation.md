# 任务概览：可控跟随与有证据的速率

2026-11-03。用户在上一轮交付后授权“如果可以判断状态稳定，可以继续推进”。主控复核5e7fe0c工作区/远端一致、161后端与61前端测试及构建通过（已有Starlette警告），在同一隔离worktree新建feat/live-task-observation，保留上一轮分支。本轮设计由既有自主授权覆盖。

## 目标与取舍

让用户照看训练/早报时不再反复刷新，并看懂服务器当前CPU/流量。候选还包括任务启动器和大文件传输；前者引入远端写入/生命周期，后者不解决主要的状态查看痛点。本轮选择已存在概览工作流的深入打磨，日志/文件继续手动读取，不新增调度、通知、聊天或远端常驻Agent。

## 观测证据

固定只读Linux采集器新增sampling={boot_id,monotonic_seconds}；CPU保留percent:null，另带ticks的user/nice/system/idle/iowait/irq/softirq/steal累计值；不再次累加guest/guest_nice。网络条目新增ifindex身份（未知为null），保留累计字节。字段增量，旧字段/CLI不破坏；不得在单次读取中编造百分比/速率，不额外sleep远端取第二样本。

CPU百分比由两次ticks差值计算非idle/iowait占比；网络B/s为同接口字节差/远端单调时间差。仅同boot_id、同目标、同接口ifindex，且0.5<=dt<=120秒、有限安全非负数、相应计数不回退时有效。重启、断线、暂停恢复、目标改绑、接口更换、计数回退或间隔过长后等待新基线；首次采样显示采样中或不可用，不显示假零。不将整机数据归因于任务，不将活动判作任务成功。

观测返回context={workload:{id,server_id,root_path,log_path,pid,process_identity},server:{id,host,port,username}}，由后端数据库受权对象生成，不含密码/凭据。UI核对context与当前任务/服务器；不匹配或缺失时不接受新数据，保留旧数据并明确标为过期，暂停自动跟随，提供刷新任务信息入口。它是观测时上下文，不承诺远端快照原子性。

## 跟随体验

仅任务概览支持自动跟随，默认关闭，保留打开任务的一次观测。用户可开启并输入2至60秒的整数间隔（默认5），无效输入说明并暂停，不能静默钳制。每次请求结束后再计时，手动/自动共享单请求门禁。失败保留旧数据/时间、清空速率基线并指数退避，最多60秒；手动重试可立即发起，成功重置退避。

离开概览、页面隐藏、暂停或卸载时清理计时/取消在途请求并使迟到结果失效；可见且回到概览后，若跟随仍开则立即重新采样。保留上一轮同ID绑定签名规则；改绑清空旧现场，单纯改名称/备注或刷新保持上下文。只读采集依旧遵守既有截止时间和大小上限。取消浏览器请求不承诺撤销已开始的后端SSH读取。

## 验证

行为测试覆盖计数解析和降级、同一采集器在Linux夹具运行、CPU/网络差分边界、非重叠调度/退避/可见性/清理、上下文改绑和迟到响应。复用隔离SSH/MySQL脚本；浏览器观察真实两次采样、暂停与恢复、改绑提示，保存截图。独立分任务与整分支审查后小提交推送新分支，不合并main、不部署、不操作真实tailnet/GPU/服务器。

参考：[内核proc文档](https://docs.kernel.org/filesystems/proc.html)、[接口统计](https://docs.kernel.org/networking/statistics.html)、[proc_stat](https://www.man7.org/linux/man-pages/man5/proc_stat.5.html)。iowait可能回退，必须判为无效区间；按此定义的CPU非空闲占比包含steal。
